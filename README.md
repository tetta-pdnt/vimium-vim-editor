# Vimium Text Editor

Vimium から入力欄をヒント選択し、Ace の Vim キーバインドで編集する独立した Chromium 拡張です。Surfingkeys は実行時に必要ありません。

## 使い方

1. `vivaldi://extensions`（Chrome なら `chrome://extensions`）を開きます。
2. 「デベロッパーモード」を有効にして「パッケージ化されていない拡張機能を読み込む」を押します。
3. このリポジトリのフォルダを選択し、対象のページを再読み込みします。
4. Vimium の通常モードで `I` を押し、画面に表示された2文字のヒントを入力します。
5. Ace の Vim エディターで編集し、`ZZ`、`:wq`、`Ctrl+Enter`（macOS は `⌘+Enter`）、または Save ボタンで反映します。

`Esc` は Vim のノーマルモードへ移動します。エディターを破棄して閉じるには Cancel ボタンか `:q!` を使います。

## Vimium と一緒に使うとき

- 拡張は Vimium のキー処理より前にページのキーイベントを捕まえ、通常モードの `I` でヒント選択を始めます。追加の Vimium マッピングは不要です。
- テキスト入力欄にフォーカスがある間は、大文字の `I` は文字として入力できるようにしています。フォーカス中の欄を直接エディターで開く場合は `Alt+I` を押します。
- `textarea`、文字入力用の `input`、および `contenteditable` を対象にします。表示中の入力欄だけをヒント表示します。
- 対応ページは `http://` と `https://` です。新しい拡張機能を読み込んだあと、すでに開いているタブは再読み込みが必要です。

## 独立性

入力欄の探索、ヒント選択、値の反映、エディターの表示はこの拡張が行います。Surfingkeys の設定・スクリプト・メッセージング API には依存しません。Ace の JavaScript は `vendor/ace.js` に同梱しています。
